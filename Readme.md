## Listing Rules:

### 👉 Implicit Binding

```text
Implicit Binding মানে হলো – কোনো অবজেক্টের ভেতরে যখন কোনো ফাংশন থাকে, আর তুমি সেই ফাংশন কল করো অবজেক্টের মাধ্যমে, তখন জাভাস্ক্রিপ্ট স্বয়ংক্রিয়ভাবে (this) কীওয়ার্ডটাকে সেই অবজেক্টের সাথে বেঁধে (bind) দেয়।
```

### 👉 Explicit Binding

```text
Explicit Binding মানে হলো — তুমি নিজেই স্পষ্টভাবে (explicitly) বলে দিচ্ছো this কার দিকে ইঙ্গিত করবে।
অর্থাৎ, জাভাস্ক্রিপ্টকে নিজে থেকেই বুঝতে না দিয়ে, তুমি call, apply, অথবা bind মেথড ব্যবহার করে this-এর ভ্যালু নির্ধারণ করো।
```
