## 👉 Prototype

```text
JavaScript এ Prototype হচ্ছে একটা inheritance (উত্তরাধিকার) সিস্টেম।
মানে তুমি একটা object বানালে, তার পেছনে একটা hidden object লুকানো থাকে যেটাকে বলে prototype object।
যখন তুমি কোন property বা method call করো আর ওই object এ না পাও, তখন JavaScript prototype chain ধরে উপরের দিকে খুঁজে দেখে।

- Prototype হলো JavaScript-এর অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং-এর মূল ভিত্তি।
- এটি অবজেক্টগুলোর মধ্যে প্রোপার্টি এবং মেথড শেয়ার করতে সাহায্য করে।
- Prototype chain এর মাধ্যমে JavaScript প্রোপার্টি খুঁজে বের করে।
- Constructor function এবং ES6 ক্লাস ব্যবহার করে prototype-ভিত্তিক inheritance সহজে করা যায়।

```
